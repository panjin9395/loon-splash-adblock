# Loon 开屏广告精简合集

v0.1.0 是可审查的闲鱼小首版，不是全 App 广告合集。目前只有 1 条闲鱼开屏专用接口规则、1 个精确 MITM 域名，无 JavaScript、远程 jq、远程替换文件、数据上传或持久化。其余候选见 coverage.md，未纳入即不生效。

## 单订阅入口

https://raw.githubusercontent.com/panjin9395/loon-splash-adblock/main/splash-adblock.lpx

固定版本：
https://raw.githubusercontent.com/panjin9395/loon-splash-adblock/v0.1.0/splash-adblock.lpx

在 Loon 插件页面添加 URL，不要作为整份配置导入。使用已有可信 MITM 证书和 Rewrite 功能；不上传证书，不修改 DNS、SSID、节点、Host 或任何系统服务。本插件使用 Loon 官方仍记录的旧版兼容语法；Loon 专有解析及手机效果未实测。

## 作用与限制

只对 acs.m.goofish.com 上公开规则记录的 idlecommerce.splash.ads 开屏路径返回空 JSON。严格限制 HTTPS、完整域名、数字主次版本和尾部边界。没有 async 接口证据及完整授权，不扩展它；某些版本可能因此仍出现广告。没有真实抓包响应或手机冷启动验证，不能保证当前版本去广告成功，也不把网络下载成功当业务成功。

MITM 的边界是整个 hostname，而不是 URL：虽然只有开屏请求会改写，启用后该主机的其他 HTTPS 请求也可能经过本地 TLS 解密。插件不读取/上传它们，也没有登录/支付/订单改写。如果不接受主机级解密，请不要启用本插件。遇到证书固定或连接失败立即关闭本插件，不关闭系统 TLS 校验。

## 旧插件如何处理

- FleaMarket_remove_ads.lpx（可莉闲鱼去广告）：不要与本插件同时用于效果验收。要只处理开屏，可临时关闭这一条旧插件，再启用本插件。旧插件的历史镜像还包含推荐流、签到入口、个人页和订单详情清理；停用会失去这些额外功能，本首版并不替代它们。若仍需要这些功能，保留旧插件并先不启用本首版。原站当前内容获取受限，不把历史镜像当作最新完整审计。
- Remove_ads_by_keli.lpx、BlockAdvertisers.lpx 以及其他综合规则：本次未逐条取得和审核最新内容，保留原状，不要求整批停用。它们可能提前拦截开屏请求，造成新插件无命中；验收时记录冲突，不能因此认定本插件有效。
- B站、知乎、淘宝、京东等单 App 插件，以及 BoxJS、签到、比价、天气、节点工具：保留。首版不覆盖这些功能，也没有审查或认可其全部供应链。
- 若综合插件与本插件冲突，仅在可定位具体开屏规则时处理该规则；不要为消除一个冲突而批量关闭其他功能。

没有自动修改原配置或手机，也不提供未经冲突验证的私密合并配置。

## 验收与回退

1. 备份当前手机配置；只添加本插件。按上文避免旧闲鱼插件重复处理。
2. 在 Loon 确认插件解析无错误，查看生效 MITM 与 Rewrite，不能关闭 TLS 校验。
3. 冷启动闲鱼，记录 iOS/Loon/闲鱼版本与是否命中精确开屏 URL；分别观察开屏、首页、搜索、消息和正常登录状态。仅观察正常使用，不为测试发起付款/下单。
4. 缓存广告可能在初次启动保留，不建议直接卸载或清除重要数据。若未命中，反馈脱敏路径与版本，不分享 Cookie、令牌、完整抓包或证书。
5. 异常时关闭或删除本插件，恢复刚才关闭的旧闲鱼插件即可。其余设置未改，无需重置全配置。升级回退可改用先前版本 tag URL。

## 本地构建与测试

Python 3，无第三方依赖，无需联网执行构建/测试：

    python build.py
    python test_release.py

tests-report.json 记录实际执行结果。测试使用人工构造的 URL 边界样例，不是假装真实流量；无 JavaScript，所以脚本 fixture 执行不适用。Loon 返回空 JSON 的语义来自官方文档，不以自制模拟器冒充 Loon 运行。
