# Loon 开屏广告精简合集

v0.2.0 为阶段性多 App 预发布：13 个候选 App、17 条精确 URL 规则、16 个明确 MITM 主机。不是全覆盖，也不是已验证这 13 款当前版本都有效。无 JavaScript、远程 jq、远程替换文件、上传或持久化。

## 单订阅入口

https://raw.githubusercontent.com/panjin9395/loon-splash-adblock/main/splash-adblock.lpx

固定版本：https://raw.githubusercontent.com/panjin9395/loon-splash-adblock/v0.2.0/splash-adblock.lpx

已有订阅只需更新该插件，不重复导入全配置。使用已有可信 MITM 证书和 Rewrite 功能，不上传证书、不改 DNS、节点或系统服务。

## 本版纳入

闲鱼（原规则保持不变）；新增拼多多、大众点评、高德地图、微博、知乎、腾讯新闻、起点、去哪儿、得物、亚朵、小宇宙、51Job。

仅保留固定上游记录的开屏接口分支，收窄到 HTTPS、精确 host、完整路径及可选查询串；reject 为断开连接，reject-dict 为 200 空 JSON，保持上游原动作。未加入同模块的首页推荐、签到、会员、播放广告、订单、支付等行为。严格路径可能漏拦新版或带额外斜杠的请求，不凭猜测放宽。

2026-10-20 用户报告 v0.1.0 闲鱼开屏已拦截，Loon 详情截图显示原规则成功解析。未提供闲鱼版本、命中日志或正常功能全面回归。新增 12 款均尚未手机验证；App Store 身份/商店版本核验不等于规则适配。上游未声明这些规则适用的 App 版本，不能保证当前版本有效。

MITM 解密范围是整个 hostname，不是开屏 URL。虽然只修改选中开屏请求，同主机的登录等其他 HTTPS 请求仍可能经过本地 TLS 解密。插件不读取或上传这些请求；若不接受主机级解密，请不要启用。遇到证书固定、连接失败或业务异常，关闭插件，不关闭 TLS 校验。完整主机清单见 splash-adblock.lpx 的 Mitm 段。

## 剩余范围

285 个原始候选标签全部完成一轮限定来源标题/别名和开屏标记筛查，但不是全部逐行代码审计。140 项有来源线索待深审，111 项在限定来源未命中待扩查，21 项金融/政务支付边界保守排除，13 项纳入本版。未命中不等于没有规则，同品牌标题命中也不等于对应 App。

详见 coverage.md、screening.json、AUDIT.md。京东、美团、B站、网易云音乐、爱奇艺、什么值得买等仍有具体语义或依赖阻塞，不能把本版称为“全部补齐”。未纳入项不会因名单存在而生效。

## 旧插件和冲突

- 闲鱼 FleaMarket_remove_ads.lpx：验收开屏时与本插件二选一。旧插件历史镜像还包含推荐流、签到入口、个人页和订单详情清理；本版不替代这些额外功能。原站最新内容未完整审计。
- 本版新增的 12 款若已有单 App 去广告插件，可能重复匹配；先核对具体开屏 URL。需要旧插件其他功能时不要直接整包删除。无法隔离重叠规则时，暂不同时启用，分别验收；不能把旧插件效果归功于合集。
- Remove_ads_by_keli.lpx、BlockAdvertisers.lpx 等综合规则保留原状，未完成最新内容逐条冲突审计，不要求整批停用。B站、淘宝、京东等未纳入插件及 BoxJS、签到、比价、天气、节点工具不动。
- 没有自动修改私人配置或手机，不提供未经冲突验证的合并全配置。

## 验收与回退

1. 备份手机配置，更新已有插件。核对 Loon 解析与生效主机，不关闭 TLS 校验。
2. 对自己安装的上述 App 分别冷启动，记录版本、开屏状态、精确 URL 是否命中；检查首页、搜索、消息、地图/播放等正常业务。不为测试发起付款或订单。
3. 缓存广告可能保留，不直接清除重要数据或卸载。反馈脱敏路径与版本即可，不分享 Cookie、令牌或完整抓包。
4. 异常时关闭本插件，恢复之前关闭的旧插件。或将插件地址改为仅闲鱼的 v0.1.0：
   https://raw.githubusercontent.com/panjin9395/loon-splash-adblock/v0.1.0/splash-adblock.lpx

## 构建与验证

Python 3，无第三方依赖，离线运行：

    python build.py
    python test_release.py

tests-report.json 为实际测试结果；URL 是人工边界用例，不是假抓包。覆盖 host 伪装、路径尾界、正常登录/支付等不匹配、各规则交叉不匹配、源规则包含所选样例、构建一致性、候选完整性和公开文件敏感模式扫描。无脚本，因此脚本 fixture 不适用。自制测试不是 Loon 运行模拟器，新增规则原生解析仍待手机验收。
